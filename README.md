# Takt Studio

## 1. Описание проекта

Takt Studio — информационная система управления танцевальной студией. Система предназначена для автоматизации расписания занятий, записи клиентов в группы, учёта посещаемости, контроля оплат и взаимодействия между клиентами, преподавателями и администрацией.

## 2. Пользователи системы

- **Клиент** — просматривает расписание, записывается на занятия и проверяет свои посещения.
- **Преподаватель** — работает с группами и отмечает посещаемость.
- **Администратор** — управляет расписанием, группами, записями и оплатами.
- **Руководитель студии** — получает информацию о работе студии и отчёты.

## 3. Основные возможности

1. Регистрация и авторизация пользователей.
2. Просмотр расписания и запись на занятия.
3. Управление группами и преподавателями.
4. Учёт посещаемости занятий.
5. Контроль оплат и абонементов.
6. Отправка уведомлений об изменениях расписания.
7. Формирование отчётов и статистики.

## 4. Структура документации

В папке `docs` находятся документы проекта:

- `user-guide.md` — руководство пользователя с инструкциями по записи на занятия и просмотру посещений.
- `CHANGELOG.md` — история изменений проекта.
- `change-request.md` — описание запроса на изменение системы.
- `review.md` — результаты проверки и замечания по проекту.
- `sprint-plan.md` — планирование работ по спринту.
- Документы практических заданий — материалы по проектированию, требованиям и развитию системы.

В папке `diagrams` хранятся диаграммы проекта.

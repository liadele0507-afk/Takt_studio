
# Takt Studio

## Описание проекта

Takt Studio — информационная система управления танцевальной студией. Система предназначена для автоматизации расписания занятий, записи клиентов в группы, учета посещаемости, контроля оплат и взаимодействия между клиентами, преподавателями и администрацией.

## Основные возможности

1. Регистрация и авторизация пользователей.
2. Просмотр расписания и запись на занятия.
3. Управление группами и преподавателями.
4. Учет посещаемости.
5. Контроль оплат и абонементов.
6. Отправка уведомлений об изменениях расписания.
7. Формирование отчетов и статистики.

## Пользователи системы

- Клиент.
- Преподаватель.
- Администратор.
- Руководитель студии.

## Документация

В папке `docs` хранятся материалы проектирования системы: требования, пользовательские сценарии, описание архитектуры, UML-диаграммы и тест-кейсы.

## Основные возможности системы

- Управление расписанием занятий.
- Запись и отмена записи клиентов.
- Учёт посещаемости занятий.
- Управление абонементами и оплатами.
- Отправка уведомлений клиентам.
- Формирование отчётов для руководства студии.

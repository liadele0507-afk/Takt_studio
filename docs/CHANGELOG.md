
# История изменений проекта Takt Studio

## 1.1.1
- Добавлено НФТ 13: после 5 неверных попыток ввода пароля учетная запись блокируется на 15 минут.
- Предусмотрена отправка пользователю уведомления о попытках входа.

## 1.1.0
- Уточнены функциональные и нефункциональные требования системы.
- Добавлено требование об отмене записи на занятие.
- Разработан дополнительный тест-кейс № 11 для проверки отмены записи.
- Обновлена матрица трассировки требований.
- Дополнены выводы по результатам проверки документации.
- Выявлена необходимость дополнительных тестов для управления клиентами и просмотра статистики.

## 1.0.0
- Подготовлено описание проекта Takt Studio.
- Сформированы функциональные и нефункциональные требования.
- Разработаны пользовательские сценарии.
- Описана архитектура системы.
- Подготовлены UML-диаграммы.
- Составлены тест-кейсы для проверки основных функций системы.

# Запрос на изменение проекта Takt Studio

## Название
Добавление функции записи в лист ожидания.

## Причина
Количество мест в танцевальных группах ограничено. Если все места заняты, клиент не может записаться на занятие. Лист ожидания позволит клиентам получить возможность записаться при освобождении места.

## Какие требования добавятся
- Клиент может записаться в лист ожидания, если группа заполнена.
- Система уведомляет клиента об освободившемся месте.
- Администратор может просматривать список ожидающих клиентов.
- Клиент может отказаться от места в листе ожидания.

## Что нужно изменить
- Функциональные требования.
- Модуль записи на занятия.
- Модуль уведомлений.
- Базу данных.
- UML-диаграмму классов (добавить класс WaitlistEntry).
- Пользовательский сценарий записи в лист ожидания.
- Добавить тест-кейсы для проверки новой функции.

## Новая версия
1.2.0 — добавляется новая функциональная возможность.

## Статус
Предложено. Задача добавлена в бэклог для дальнейшей реализации.
